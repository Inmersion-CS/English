# English

Open-source web learning environment for English with a focus on computing and academic communication.

> **Status:** Foundation v0.1. Full reading/listening modules, speaking activities, writing feedback, vocabulary systems, and assessments are roadmap items, not implemented features yet.

**Live site target:** https://inmersion-cs.github.io/English/

## Why this project exists

Technical knowledge is more useful when it can be understood and communicated clearly. This project will connect English practice with the kinds of reading, listening, explanation, writing, and presenting used in computing and academic study.

## Learning scope

Planned areas include academic reading, technical vocabulary, listening comprehension, speaking and explanation, writing, presentation language, and computing-specific communication.

## Current features

Foundation v0.1 supplies an accessible React + TypeScript shell, English-specific routes and roadmap, dependency audit, tests, strict type checking, linting, production build, Pages automation, and open-source project files.

## Roadmap

1. Academic reading
2. Technical vocabulary
3. Listening and speaking
4. Writing and presenting
5. Later: integrated practice and assessment experiences

## Development

Node.js 22.13+ is required.

```bash
npm ci
npm run dev
npm audit --audit-level=high
npm run typecheck
npm run lint
npm run test:run
npm run build
```
